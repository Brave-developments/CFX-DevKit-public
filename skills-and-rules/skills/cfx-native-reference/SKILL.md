Use cfx_native_status first. If only seed data is installed, explicitly tell the user the coverage is incomplete. With their permission enable CFX_ENABLE_NETWORK=1 and call cfx_sync_natives to cache the two official Cfx native JSON datasets. Search with cfx_search_natives and confirm exact signatures through cfx_native_detail; where apiset is unverified, do not claim server/client compatibility.

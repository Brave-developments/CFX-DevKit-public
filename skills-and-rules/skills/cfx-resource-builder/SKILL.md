---
name: cfx-resource-builder
description: Safely plan and generate simple FiveM Lua resources, with Qbox, QBCore, ESX, or standalone selection.
---
Detect the framework before choosing it. Prefer cfx_resource_preview first and review all generated files. cfx_scaffold_resource is optional and disabled by default. Ask for explicit user permission before any writes; enable CFX_ENABLE_WRITES=1 only in trusted development environments. Never overwrite an existing resource or put secrets in client-side code. Before deployment, validate the manifest and audit security. Do not describe the basic scaffold as production-ready.

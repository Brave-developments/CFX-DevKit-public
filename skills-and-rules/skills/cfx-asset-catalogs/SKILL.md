---
name: cfx-asset-catalogs
description: Search GTA V/ FiveM movement clipsets, particle effects, scenarios, interiors, IPLs, vehicles and peds without RedM data.
---
Use cfx_asset_catalog_status first and never imply a source is present without a successful local sync. Enable CFX_ENABLE_NETWORK=1 only on explicit approval to download specific assets. Use cfx_search_asset_catalog with proper catalog and optional search_clips, and cfx_validate_asset_pair before providing particle/movement code via cfx_asset_lua_example. Note that movement clipsets, animation dictionaries and scenarios have different native APIs. Verify client-side behavior in a FiveM development build. Do not redistribute upstream extracts that lack a clear license.
